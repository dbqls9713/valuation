# Stream 4: 가격 평가 (종목 특성별 도구 선택)

**입력**: 현재가, Stream 3 시나리오 명세, Stream 2 경영진 가이던스 해석, Stream 1 산업 10년 전망 + 해자 분석, 터미널 스테이지 가정
**산출**: 종목 특성에 맞는 도구로 IV/CAGR 산출 + Reverse 역산 + 확률가중 + 과신 점검 + 매수금지/회색/매수가능 판정
**선행**: Stream 3 완료. Stream 1·2 강하게 권장
**작업 시간**: 반나절 ~ 1일
**병렬**: Stream 5와 동시 진행 (Stream 4의 IV 산출이 Stream 5 시장 의견에 anchored 안 되도록)

## 4-근간 철학

가격 평가의 본질은 두 가지

1. **매수 금지 필터** — "가장 낙관적 가정으로도 리스크프리 이하면 비싸다". 매수 적기는 정의하지 않는다 (허상)
2. **시장 가정과 우리 가정 차이 진단** — Reverse 역산으로 시장이 가격에 반영하는 가정을 역으로 추론, 우리 가정과 비교

멍거: *"ROIC가 40년간 6%인 기업을 할인가에 사도 수익은 6%에서 크게 벗어나지 않는다. 반대로 ROIC 18%가 20~30년 지속되는 기업은 비싸게 사도 좋은 성과를 낸다."*
→ **사후적 수익률의 상한선은 ROIC가 결정한다. 가격이 아님.**

매도 시점 필터로 사용하지 않는다 — 보유 중에는 가격이 아닌 해자 건강도(Stream 8)를 감시한다.

**Shallow-Deep 역할 구분**: Shallow Phase 10은 간이 도구로 매수 금지 trigger 감지용 (Phase 10-A: EPS×PER DCF / Phase 10-B: ROE×PBR — 트랙별 분기, 별도 PR에서 통합 예정). Deep Stream 4는 **종목 특성에 맞는 도구 선택** + 양 도구 cross-check + Reverse 역산 + 확률가중 + 과신 점검.

**트랙별 분기 제거**: 기존엔 Buffett 트랙 = DCF 주력, Fisher 트랙 = EPS×PER 주력으로 나뉘었으나, 종목 특성에 따라 적합한 도구가 다르므로 **트랙 무관 종목 특성별 선택**으로 통일.

## 4-A. 종목 특성 진단

Stream 1·2 산출물 기반으로 종목 특성 진단 → 적합 도구 선택.

### 진단 항목

| 항목 | 측정 | 해석 |
| --- | --- | --- |
| 자본 집약도 | CAPEX / 매출 (5년 평균), 무형자산 비중 | 높음 → EV/EBITDA·ROIC×EV/IC / 낮음 → EPS·DCF |
| 이익 안정성 | 영업이익률 5년 변동성 | 높음 → 사이클 평준화 (Mid-cycle EPS) / 낮음 → 그대로 |
| 자사주 매입 | 5년 주식수 변화 CAGR | -5% 이상 → DCF (OE/Share, EPS 왜곡) / 미미 → EPS×PER 가능 |
| 산업 특성 | 사업 모델 | 표 참조 |
| 이익 부호 | EPS > 0 여부 | 음수 → P/S, Rule of 40 / 양수 → EPS·PER 가능 |

### 종목 유형별 권장 도구

| 종목 유형 | 1순위 도구 | 2순위 (보조) | 이유 |
| --- | --- | --- | --- |
| 소비재·소프트웨어·플랫폼 (광고·검색·SaaS 안정기) | EPS × PER | DCF (OE) | 이익 창출이 본체. EPS·PER 직관적 |
| 금융주 (은행·보험) | **ROE × PBR** | DCF | 자본집약, book value가 valuation 본체. EPS는 dilution 노이즈 |
| 부동산·REIT | NAV (자산 가치) | FFO/AFFO 배수 | 자산 가치가 본체 |
| 자본집약 산업 (반도체·중공업) | EV/EBITDA | ROIC × EV/IC | EBITDA·자본 효율이 핵심 |
| 자사주 매입 heavy (5년 주식수 -5% 이하) | **DCF (OE 기반)** | EPS×PER (참고용) | EPS는 buyback에 왜곡, OE/Share가 본체 |
| 무수익·재투자 heavy (고성장 SaaS, EPS 음수) | 매출 × P/S 또는 Rule of 40 | DCF (OE 음수면 미래 OE 추정) | EPS 음수면 PER 무의미 |
| 사이클러컬 (에너지·석유화학·철강) | EV/EBITDA + Mid-cycle 정상 EPS | DCF | 사이클 평준화 필요 |

### 도구 선택 결정

종목 특성 진단 후 **1순위 + 2순위** 도구 두 개 선택. 4-B에서 양쪽 모두 산출. 단일 도구로 결정하지 않는 이유: cross-check (한 도구의 약점을 다른 도구가 제동).

## 4-B. 정량 산출

### 의무 도구: DCF (OE 기반) — 거의 모든 종목

`valuation/RATIONALE.md` (OE = CFO − SBC − CAPEX, SBC 미반영 한계, buyback_rate 상호작용) 참조.

#### DCF 시나리오 설계 원칙 (P4)

- **차이는 성장률로만 표현**. 할인율은 기회비용으로 고정 (Buffett principle, r=10%)
- **바이백은 자본배분의 문제이므로 DCF에서 제외** (별도 평가). buyback 효과는 shares 경로로만 반영
- OE 산출: CFO − SBC − CAPEX. 산출 경로를 TTM 기준으로 투명하게 명시
- Stream 3 시나리오 명세에 정합한 Bull/Base/Bear

#### 시나리오 산출

| 시나리오 | 매출 CAGR | 영업이익률 | OE 성장률 | terminal growth | IV |
| --- | --- | --- | --- | --- | --- |
| Bull | | | | | |
| Base | | | | | |
| Bear | | | | | |

### 보조 도구: 4-A에서 선택한 종목별 도구

#### EPS × PER (소비재·소프트웨어·플랫폼)

```text
10년 후 주당 가치 = (10년 후 EPS × 적정 터미널 PER) + 누적 배당
CAGR = (10년 후 가치 / 현재가)^(1/10) − 1
```

| 시나리오 | 10년 EPS CAGR | 터미널 PER | 누적 배당 | 10년 후 가치 | CAGR |
| --- | --- | --- | --- | --- | --- |
| 스트레스 | | | | | |
| 낙관 | | | | | |
| 기본 | | | | | |
| 비관 | | | | | |

- **낙관 EPS**: 경영진 장기 가이던스의 80% (이변 없으면 달성 가능). 100%는 스트레스용 별도 표기
- **터미널 PER**: 동종 5개 피어의 5년 평균 PER **중간값** (이상치 견제). 5개 피어 선정 기준 = **시총 아닌 사업 모델·산업 위치 유사**
- 자사주 매입 heavy 기업은 EPS 성장에 누적효과 이미 반영 — 이중계산 주의

#### ROE × PBR (금융주, 자본집약 + 자사주 매입 적은)

```text
10년 후 가치 = BV₀ × (1 + ROE × retention)^10 × terminal PBR
CAGR = ((1 + ROE × retention)^10 × terminal PBR / current PBR)^(1/10) − 1 + payout yield
```

- **유지 ROE**: 5년 평균 + 산업 보수성 반영
- **terminal PBR**: 동종 피어 5년 평균 또는 PBR 공식 역산 ((1+ROE)/(1+r))^N
- payout yield: 배당 + buyback의 합

#### EV/EBITDA (자본집약 산업)

```text
10년 후 EV = 10년 후 EBITDA × 터미널 EV/EBITDA
10년 후 주당 가치 = (EV − 부채 + 현금) / shares
```

- 자사주 매입은 shares 경로로만 반영 (EBITDA 경로에 영향 없음)

#### NAV (REIT·부동산)

- 보유 자산의 시장가 합 − 부채 = NAV
- AFFO 배수 보조

#### P/S 또는 Rule of 40 (고성장 SaaS, EPS 음수)

- 매출 CAGR + EBITDA 마진 ≥ 40 (Rule of 40)
- 미래 OE 도달 시점 추정 후 그 시점부터 DCF

## 4-C. Reverse 역산 (선택 도구별)

**일반 가치평가**: 가정 → IV → 현재가 비교
**Reverse 역산**: 현재가 → 어떤 가정이어야 정당한가? → 시장 가정 추론

목적: 시장 가정 vs 우리 가정 차이를 정량 비교. 우리가 더 낙관/보수적인지 진단.

### 도구별 Reverse

| 도구 | Reverse 산출물 |
| --- | --- |
| DCF | 현재가를 정당화하는 OE 성장률 (10년) |
| EPS × PER | 현재가를 정당화하는 EPS CAGR + 터미널 PER 조합 |
| ROE × PBR | 현재가를 정당화하는 ROE × N년 지속 조합 |
| EV/EBITDA | 현재가를 정당화하는 EBITDA CAGR + 터미널 multiple |

### 정성 비교 (수치 임계 없음)

Reverse 산출 가정과 다음 비교

- 경영진 공언 (장기 가이던스)
- 산업 CAGR (Stream 1 산출)
- 5년 자체 실적 추세
- 동종 피어 컨센서스 (Stream 5 입력 후)

비교 결과를 회고에 명시:

- 시장이 우리보다 낙관 → "왜 시장이 더 비싸게 사는가? 모르는 변수 있나?"
- 시장이 우리와 유사 → 합리성 확인
- 시장이 우리보다 보수 → 우리 Bull 가정이 너무 공격적일 가능성 점검

## 4-D. 확률가중 IV + 과신 점검 + 판정

### 확률가중 IV (L2)

DCF Bull/Base/Bear에 확률 부여. 확률은 주관적 판단이며 근거 명시 (Stream 3 시나리오 실현 조건 기반).

```text
확률가중 IV = P_bull × IV_bull + P_base × IV_base + P_bear × IV_bear
```

- 확률 합 = 1.0
- 확률 부여 근거 1줄 (예: "Cloud 가속 검증되어 Bull 30%, AI 디스럽션 불확실성으로 Bear 20%, 기본 50%")

### 과신 점검 (L3)

"내가 틀렸다면" 섹션. **Bear IV가 과대평가인 시나리오를 구체적으로 기술**.

- 우리가 Bear라고 가정한 것보다 더 나쁜 결과가 나올 시나리오는 무엇인가
- 그 시나리오의 확률은 우리 Bear 확률보다 낮은가? (낮아야 함)
- 우리 가정에 missing variable이 있다면 그게 뭔가

자기 비판 절차. Stream 6-A의 "외부 의견 대응"과 다름 — 6-A는 시장이 동의 안 한 논점에 대한 대응, 4-D 과신 점검은 우리 자체 분석에 대한 자기 검증.

### 판정 (OR 결합 — D2)

| 도구별 | 매수 가능 | 회색 | 매수 금지 |
| --- | --- | --- | --- |
| DCF | 확률가중 IV ≥ 30% 안전마진 | 0~30% | < 0 |
| EPS×PER | 낙관 CAGR ≥ 10% | 4~10% | < 4% (무위험이자율) |
| ROE×PBR | 낙관 CAGR ≥ 10% | 4~10% | < 4% |
| EV/EBITDA | 확률가중 IV ≥ 30% | 0~30% | < 0 |

### OR 결합 룰

- **둘 중 하나라도 매수 가능** → **매수 가능**
- 둘 다 회색 또는 한쪽 매수 가능·한쪽 회색 → 매수 가능
- **둘 다 매수 금지** → **매수 금지**
- 한쪽 매수 가능·한쪽 매수 금지 → 매수 가능 (OR)

OR 의 의미: 여러 도구 중 하나라도 합리적 가정에서 매수 가능하면 진입. 단 Stream 6 핵심 3조건 (#9·#14·#15) FAIL이나 6-A 가설 누락 점검 미통과 시 OR 무관 탈락.

- [ ] 4-A 종목 특성 진단 완료 + 1순위·2순위 도구 명시

## 4-주의 사항

- **자사주 매입·재투자 이중계산 방지** — 자사주 매입 많은 기업은 EPS 성장에 누적효과가 이미 반영 (`valuation/RATIONALE.md` 한계 2 참조)
- **낙관의 수준** — 경영진 공언의 80%. 명백한 공격 시나리오는 스트레스용 별도 표기
- **매도 트리거로 사용 금지** — 보유 중에는 Stream 8 모니터링이 본체
- **SBC 미반영 한계 명시** — `valuation/RATIONALE.md` 참조. SaaS·Tech 기업 분석 시 SBC 조정 OE 별도 표기
- **종목 특성 잘못 진단 시 재진단** — Stream 6 진입 전 도구 선택 적절성 재검토
