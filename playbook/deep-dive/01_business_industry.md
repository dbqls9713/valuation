# Stream 1: 제품·산업·기술 + 해자 분석

**입력**: 기업 IR 자료, 산업 리포트(전문 리서치), 학술·표준화·전문가 인터뷰, 경쟁·대체 기술 자료, 정량 지표 (ROIC·GP margin·FCF/NI·CAPEX/매출·주식수)
**산출**:

- 1-A: 제품 포트폴리오 + 다음 세대 파이프라인 + 산업 10년 전망 + 기술 변곡점 지도
- 1-B: 해자 분석 (종류·proxy·위협 vs 방어·등급 두 차원)
**선행**: 없음 (Stream 2와 병렬)
**작업 시간**: 초기 뼈대 단계에서 3~4일. 도메인 체크리스트가 쌓이면 더 길어질 수 있음

## 1-근간 철학

피셔 본인은 텍사스 인스트루먼트·모토로라·듀폰 등 **신기술 기업 투자자**였고, 버핏은 코카콜라·시즈 캔디·아멕스 등 **해자 완성기 기업 투자자**였다. 두 트랙 모두 사업·산업·기술의 **외부 이해**가 본체:

- 산업 10년 후 위치 + 기술 변곡점 (피셔형 N+1차항 가정의 근거)
- 해자 작동 메커니즘 + 강도 (버핏형 ROIC 지속의 근거)

경영진 축(Stream 2)만으로 분석을 완결하면 반쪽짜리. 사업·산업·기술 + 해자가 독립 축으로 자리잡아야 N+1차항·ROIC 지속 가정에 설득력이 생긴다.

피셔 15 중 조건 1(매출 성장 잠재력)·11(산업 특화 경쟁력)을 질적으로 뒷받침. Buffett의 해자 평가도 본 Stream의 1-B에서.

## 1-A. 사업·산업·기술 이해

### 뼈대 작업

#### 매출 분해 (두 축 + 추적 가능성 구분)

- **제품 기준 매출 분해** (가장 직관적): 제품/서비스 계열별 % + 5년 추이
- **공시 기준 매출 분해** (회사가 실제 보고하는 세그먼트/고객 그룹): 공시 변경 이력 포함. 신/구 기준 모두 파악하되 앞으로 추적 가능한 축 우선
- **분기별 추적 가능 지표 구분**:
  - 공시되는 것 (회사가 직접 발표): 그대로 사용
  - 추정해야 하는 것: **추정 근거를 명시**

원칙: 수치는 **공시**와 **추정**을 명확히 구분. 추정이면 산출 근거 명시.

#### 다음 세대 파이프라인

- 공개된 제품 로드맵 (R&D 단계 product N+1, N+2, N+3)
- 인접 시장 진출 계획
- M&A 파이프라인 (있다면 Stream 2 자본배분과 연계)

#### 산업 구조

- 공급사슬 상의 위치
- 5 Forces 간이 적용 (5개 항목 전수)
- 진입장벽·전환비용의 구조적 위치
- 세그먼트별 경쟁 지형, 시장 점유율, 주요 경쟁자

#### 산업 성장 경로 10년

- 산업 자체가 커질지 / 축소될지
- 대체 산업 위협 여부
- 외부 리서치 ≥ 2개 인용 (전문 리서치 하우스·학술 논문)

#### 기술 변곡점 지도

- 현재 지배적 기술과 도전 기술
- 이 기업이 어느 쪽에 있는지
- 변곡점 도래 예상 시점
- 변곡점 후보 ≥ 2개 식별

#### 외부 자료

- 산업 리포트(전문 리서치 하우스), 학술 논문, 표준화 동향, 전문가 인터뷰, 업계 유튜브
- 출처 ≥ 3개

## 1-B. 해자 분석 (NEW — Buffett Sec 2 보강)

### 근간 철학

해자는 "**왜 이 회사가 ROIC를 지속하는가**"의 본체. Buffett 트랙에서는 가장 중요한 정성 분석. Fisher 트랙에서도 N+1차항 지속의 구조적 이유를 설명.

해자 등급은 **두 차원**으로 표기 — 정적 상태가 아닌 동적 진행을 보기 위해:

- **상태 (HIGH / MEDIUM / LOW)**: 현재 해자 강도
- **방향 (강화 / 유지 / 약화)**: 시간에 따른 진행

피셔형 (해자 형성·확장 중) 적용 가능. 예: 2000년대 아마존은 상태 LOW + 방향 강화 → 미래 ROIC 가정 정당화.

### "Figma 사례" 트래킹

뾰족한 전문 서비스가 종합 플랫폼의 특정 영역을 대체하는 패턴.

- 본 종목이 종합 플랫폼이면: 어떤 전문 서비스가 어느 영역 대체 위협? 현 시점 + 향후 3~5년
- 본 종목이 전문 서비스면: 종합 플랫폼이 본 영역 잠식 위협? + 다른 전문 서비스 경쟁?

이 패턴은 Stream 8 모니터링과 연결됨.

## 1-Acceptance Criteria

PR 2에서 보강 예정. 초안:

- 1-A:
  - [ ] 매출 mix 100% 분해 — **제품 기준 + 공시 기준 두 축** (P1)
  - [ ] 분기별 추적 가능 지표 — **공시 vs 추정 명확히 구분** (P2)
  - [ ] R&D 파이프라인 N+1, N+2, N+3 product 명시 (≥ 3개)
  - [ ] 산업 10년 CAGR 정량 (외부 리서치 ≥ 2개 인용)
  - [ ] 5 Forces 5개 항목 전수 작성
  - [ ] 기술 변곡점 후보 ≥ 2개 + 각 변곡점에서 회사 위치 명시
  - [ ] 외부 자료 출처 ≥ 3개
- 1-B:
  - [ ] 해자 종류 6개 전수 평가 (작동 메커니즘 + proxy + 상태 + 방향)
  - [ ] 정량 proxy 5년 추이 표
  - [ ] 해자 위협 vs 방어 대칭 매핑 ≥ 3쌍
  - [ ] "Figma 사례" 식별 (위협 또는 방어 입장)
  - [ ] See's 테스트 3조건 평가
  - [ ] 해자 등급 종합 (상태 + 방향) 1줄

**PASS**: 1-A 7개 + 1-B 6개 모두 충족.

## 1-Anchoring 차단

PR 2에서 보강 예정. 차단 대상: **Shallow Phase 5 (산업 지도)** + **Phase 6-A (버핏 해자)**. Stream 1 종료 후 비교, 결과를 회고에 기록.

## 1-트랙별 분기

거의 없음 (공통).

- Buffett 트랙은 1-B 해자 분석에 더 무게 (해자 완성기 → ROIC 지속 가정의 본체)
- Fisher 트랙은 1-A 다음 세대 파이프라인·기술 변곡점에 더 무게 + 1-B는 해자 형성·확장 추세에 무게 (방향이 강화)

## 1-발전 단계 명시

> **이 Stream은 현재 1-A가 가장 얇다.** 도메인(반도체, 제약, 소비재, 금융, 플랫폼 등)별로 필요한 자료·질문·방법론이 근본적으로 다르기 때문에, 사례 없이 체크리스트를 완성하면 오히려 오도된다. 실제 Deep Dive를 돌리면서 도메인별로 필요했던 것·부족했던 것을 회고에 누적하고, 사례 N건 이상 쌓이면 1-A를 도메인별 세부 체크리스트·방법론으로 개정한다. 1-B 해자 분석은 Buffett·Fisher 모두 공통 프레임이라 상대적으로 안정.
