## 2. 2분 테스트 + 사업모델 (Phase 2)

### 2분 테스트

Fortinet은 기업과 통신사에게 네트워크 보안 어플라이언스(appliance, 보안 전용 하드웨어 장비)인 FortiGate와 통합 보안 플랫폼(Security Fabric)을 판매하여 돈을 번다. 자체 설계한 보안 전용 ASIC 칩(FortiASIC SPU — FortiGate 어플라이언스 내부에 탑재되어 패킷 검사·암호화·침입방지 등 보안 연산을 범용 CPU 대비 최대 10배 빠르게 처리)으로 경쟁사 대비 가격 대비 성능 우위를 확보하고, 한번 설치된 어플라이언스 위에 구독형 보안 서비스를 올려 반복 매출을 만든다. 커스텀 실리콘 기반의 가격/성능 우위와 500,000개 이상의 설치 기반이 전환 비용을 형성하여 훌륭할 수 있다.

### PBR 공식 역산

buyback 집약 기업이므로 ROIC + EV/IC 변형 사용:

```text
EV/IC = ((1+ROIC)/(1+r))^N

IC = 총자산 − 유동부채 − 현금 = $10.39B − $5.03B − $2.50B = $2.86B
EV = 시총 + 총부채 − 현금 = $60.9B + $9.15B − $2.50B = $67.5B
EV/IC = 23.6x
ROIC = 56.9%

r=10%: 23.6 = (1.569/1.10)^N → N = ln(23.6)/ln(1.426) = 8.9년
r=12%: 23.6 = (1.569/1.12)^N → N = ln(23.6)/ln(1.401) = 9.4년
```

시장은 ROIC 57% 수준이 **약 9년** 지속된다고 가정하고 있다. Fortinet의 ASIC 기반 원가우위와 Security Fabric 전환비용을 고려하면 도달 가능하나 보수적이지는 않은 가정.

## 10. 간이 3시나리오 Valuation (Phase 10) — Fisher 분기

### 10-B. Fisher 기대 CAGR (ROE x PBR)

buyback 집약 기업(FY2022-23 equity 음수)이므로 **ROIC + EV/IC 변형** 사용.

단, 이 기업은 NOPAT의 100% 이상을 buyback으로 환원하여 IC 성장이 거의 없으므로, 순수 ROE×PBR 공식(book 복리 전제)이 왜곡된다. 아래 공식 결과를 보조 지표로 제시하고, **EPS 기반 CAGR 보조 분석**으로 보완한다.

#### 10-B-1. 시나리오 가정 매트릭스

| 변수 | Bull | Base | Bear |
| --- | :-: | :-: | :-: |
| 유지 ROIC | 55% | 40% | 25% |
| 예상 지속 년수 N | 15 | 10 | 7 |
| 터미널 EV/IC | 12x | 5x | 1x |

**터미널 EV/IC 가정 근거**:

- Bull: ASIC+플랫폼 해자 장기 유지 → 15년 후에도 높은 프리미엄
- Base: 경쟁 심화로 ROIC 점감하나 해자 부분 유지
- Bear: 클라우드 전환으로 ASIC 우위 소실, 범용 보안 업체로 수렴

#### 10-B-2. Risk / Opportunity 매핑 (Phase 8 연계)

| 항목 | Bull 전제 | Base 전제 | Bear 전제 |
| --- | --- | --- | --- |
| Risk #1 (SASE 전환) | 해소: 하드웨어+SASE 양립 | 완만: 서서히 전환 | 실현: 하드웨어 급감 |
| Risk #2 (PANW 플랫폼화) | 해소: Fortinet 플랫폼 우위 유지 | 완만: 점유율 소폭 하락 | 실현: 대형 고객 이탈 |
| Risk #3 (CVE 신뢰도) | 해소: PSIRT 대응 강화 | 완만: 간헐적 이슈 | 실현: 반복 취약점 노출 |
| Opp #1 (SASE/SD-WAN) | 실현: SASE ARR 급성장 | 부분: 점진적 성장 | 미실현: 경쟁 열위 |
| Opp #2 (OT 보안) | 실현: OT 시장 선점 | 부분: 틈새 확보 | 미실현: 진입 실패 |
| Opp #3 (FortiAI) | 실현: AI 프리미엄 과금 | 부분: 무료 번들 | 미실현: AI 차별화 실패 |

#### 10-B-3. PBR 공식 계산

```text
r = (1+ROIC) / (EV_IC / Terminal)^(1/N) − 1

Bull:  r = 1.55 / (23.6/12)^(1/15) − 1 = 1.55 / 1.046 − 1 = 48.2%
Base:  r = 1.40 / (23.6/5)^(1/10) − 1  = 1.40 / 1.168 − 1 = 19.9%
Bear:  r = 1.25 / (23.6/1)^(1/7) − 1   = 1.25 / 1.571 − 1 = −20.4%
```

**PBR 공식 한계 주석**: 위 수치는 IC가 ROIC로 복리 성장한다는 전제인데, Fortinet은 NOPAT 100%+ 환원으로 IC가 사실상 성장하지 않는다. Bull 48%는 비현실적으로 높고, Bear -20%는 비현실적으로 낮다. 이 공식은 buyback 집약 모델에서 **신뢰 불가** → EPS 기반 보조 분석 참조.

#### 10-B 보조: EPS 기반 CAGR 분석

buyback으로 IC 성장 없이 EPS를 올리는 구조이므로, EPS × 터미널 PER로 10년 후 주가를 추정하고 CAGR 역산.

현재: 주가 $79.64, EPS $2.42 (NI $1.85B / 765M shares), PER 32.9x

| 변수 | Bull | Base | Bear |
| --- | :-: | :-: | :-: |
| 매출 CAGR (10년) | 14% | 11% | 7% |
| 터미널 EBIT 마진 | 33% | 30% | 25% |
| 주식수 연간 변화 | -3% | -2% | -1% |
| 터미널 PER | 28x | 23x | 18x |

**계산**:

```text
Bull:
  10년 후 매출 = $6.80B × 1.14^10 = $25.2B
  10년 후 EBIT = $25.2B × 33% = $8.3B
  10년 후 NI  = $8.3B × 0.78 = $6.5B
  10년 후 주식수 = 765M × 0.97^10 = 569M
  10년 후 EPS = $11.42
  10년 후 주가 = $11.42 × 28 = $319.7
  CAGR = ($319.7/$79.64)^0.1 − 1 = 14.9%

Base:
  10년 후 매출 = $6.80B × 1.11^10 = $19.3B
  10년 후 NI  = $19.3B × 30% × 0.78 = $4.5B
  10년 후 주식수 = 765M × 0.98^10 = 627M
  10년 후 EPS = $7.18
  10년 후 주가 = $7.18 × 23 = $165.1
  CAGR = ($165.1/$79.64)^0.1 − 1 = 7.6%

Bear:
  10년 후 매출 = $6.80B × 1.07^10 = $13.4B
  10년 후 NI  = $13.4B × 25% × 0.78 = $2.6B
  10년 후 주식수 = 765M × 0.99^10 = 691M
  10년 후 EPS = $3.76
  10년 후 주가 = $3.76 × 18 = $67.7
  CAGR = ($67.7/$79.64)^0.1 − 1 = −1.6%
```

#### 결과

| 시나리오 | 기대 CAGR | 판정 |
| --- | :-: | :-: |
| Bull | 14.9% | ≥ 10% 매수 가능 후보 |
| Base | 7.6% | 회색 구간 |
| Bear | -1.6% | 마이너스 구간 |

**확률가중 CAGR**: Bull 25% + Base 50% + Bear 25% = **8.4%** (Bull 기대와 Bear 리스크 균형 감안, Base에 가중)

### 10-C. Trigger 신호

**Fisher 판정**:

- **Bull CAGR 14.9% ≥ 10%** → 매수 가능 후보 (Deep 필수)
- **Bull CAGR 14.9% ≥ 4%** → 매수 금지 trigger 미해당
- **Base CAGR 7.6% < 10%** → 가장 낙관도 아닌 Base에서 10% 미달 → 회색 구간
- **확률가중 CAGR 8.4% < 10%** → 현재가에서 요구수익률 미달

**시사점**: 현재가 $79.64는 Bull 시나리오에서는 매력적이나 Base 시나리오에서 10% 허들 미달. 가격이 $65~70 수준으로 하락하면 Base CAGR이 10%에 근접하여 안전마진 확보. Deep Dive에서 시나리오 가정 정밀화가 필수.

**PBR 공식 vs EPS CAGR 괴리 주석**: PBR 공식의 Bear -20%와 EPS CAGR의 Bear -1.6%는 15pp 이상 차이. PBR 공식이 buyback 모델에 부적합하기 때문. **Deep에서는 EPS×PER DCF (Buffett 10-A 방법론)도 병행 권고** — Fisher 배정이지만 자본배분은 Buffett형.
