### PBR 공식 역산 (해자 지속기간 N)

```text
PBR = ((1+ROE)/(1+r))^N
9.93 = ((1+0.318)/(1.10))^N
9.93 = (1.198)^N
N = ln(9.93)/ln(1.198) = 12.7년
```

> 시장은 **r=10% 가정 하에 ROE 31.8%가 ~13년 지속**된다고 가정. r=12%로 보면:

```text
9.93 = (1.318/1.12)^N = (1.177)^N → N = 14.0년
```

**해석**: 시장 가정 12.7~14년의 초과수익 지속은 빅테크에서 비합리는 아니나 **DOJ 행위제한 + AI 검색 디스럽션** 두 축이 동시 시작된 시점에서는 **공격적**. 본격 판정은 Fisher Deep Stream C에서.

**ROIC 기반 보수 체크**: ROIC 22%, EV/IC = ($4.12T - $30.7B + ~$13B 부채) / ($595B - $103B - $31B) = $4.10T / $462B = 8.88x.

```text
r = (1+0.22)/(8.88)^(1/13) - 1 = 1.22/1.180 - 1 = 3.4%
```

→ ROIC 22% × 13년 지속 가정 시 r = 3.4%. **r=10% 요구 시 매우 비싸**.

## 10. 간이 3시나리오 Valuation (Phase 10) — Fisher 분기

### 10-B. Fisher 기대 CAGR (ROE × PBR)

**현재 상태**: ROE 31.8%, PBR 9.93x, payout ~52% (배당 + buyback), 잔존 retention ~48%.

#### 10-B-1. 시나리오 가정 매트릭스

| 변수 | Bull | Base | Bear |
| --- | :-: | :-: | :-: |
| 유지 ROE | 30% | 25% | 18% |
| 예상 지속 N | 10년 | 10년 | 10년 |
| 터미널 PBR | 8x | 5x | 3x |
| Retention | 50% | 50% | 50% |
| BV CAGR (= ROE × retention) | 15% | 12.5% | 9% |

#### 10-B-2. Risk / Opportunity 매핑

| 항목 | Bull 전제 | Base 전제 | Bear 전제 |
| --- | --- | --- | --- |
| Risk #1 (AI 검색 disruption) | AI Overviews로 흡수 — ad 마진 유지 | 부분 잠식 — ROE 25%로 하향 | 본격 잠식 — ROE 18% |
| Risk #2 (DOJ remedies) | 행위제한 영향 미미 — 자생 수요 견고 | 일부 default 손실 — Cloud로 보완 | 검색 점유 -10%pt + EU 추가 조치 |
| Risk #3 (Capex ROI) | $175–185B → Cloud +60%/Gemini 폭발로 ROIC 25% 회복 | 일부 회수 — ROIC 20% 유지 | 흡수 실패 — ROIC 15% |
| Opp #1 (Cloud 가속) | Cloud +50% 지속, 마진 40% | Cloud +30%, 마진 35% | Cloud +20%, 마진 25% |
| Opp #2 (Gemini 신규 수익) | API/구독 $30B 매출 신규 | $10B 신규 | 미실현 |
| Opp #3 (Waymo 등 Other Bets) | $20B 매출 + 흑자 | $5B + BEP | 미실현 |

#### 10-B-3. 계산 + 결과

**계산식**: 10년 후 가격 ≈ BV₀ × (1+BV growth)^10 × PBR_T. 현재가 ≈ BV₀ × PBR_0.
주가 CAGR = ((1+BV growth)^10 × PBR_T/PBR_0)^(1/10) - 1. 추가로 payout이 매년 ~5%/(PBR_0)분의 cash 환원으로 1.0~1.5%/yr 보조.

| 시나리오 | 자본증식 CAGR | + payout yield | 종합 CAGR | 판정 |
| --- | :-: | :-: | :-: | :-: |
| Bull | 12.6% (1.15^10 × 8/9.93)^(1/10) - 1 | +1.5% | **~14.1%** | 매수 가능 후보 (≥10%) |
| Base | 5.0% (1.125^10 × 5/9.93)^(1/10) - 1 | +1.5% | **~6.5%** | 회색 |
| Bear | -3.3% (1.09^10 × 3/9.93)^(1/10) - 1 | +1.5% | **~-1.8%** | 손실 가능 |

**확률가중 (Bull 30 / Base 50 / Bear 20)**: 0.30 × 14.1% + 0.50 × 6.5% + 0.20 × (-1.8%) = **7.1%**

**확률 추정 근거 1줄**: AI 디스럽션·DOJ remedies·capex ROI 불확실성 동시 작동 중이므로 Bear 20% 부여. Cloud 가속·Gemini scale은 검증되어 Bull 30%. 다수 Base 50%.

### 10-C. Trigger 신호

- **Bull CAGR 14.1% ≥ 10%** → Deep 진입 가능 (Fisher 기준)
- **Bull CAGR 14.1% > 4%** → 매수 금지 trigger 발동 안 함
- **Base CAGR 6.5% < 10%** → 극단 저가 신호 아님 (Deep 정밀화 필요)
- **확률가중 7.1% < 10% 요구수익률** → 현재가는 Fisher 관점으로 **풍족한 마진 없음**. Bull 시나리오에 의존해야 정당화.

**해석**: 가격이 Bull 가정에 매우 많이 의존. Bull이 되려면 capex $175–185B/yr가 Cloud +50%·Gemini API $30B 등 N+1차항으로 회수되어야 함 — 입증 필요. Phase 11에서 확신도 조정.
