# 네오팜(092730) Shallow Dive — 2026-07-01

기준일: 2026-07-01 | 데이터: 데이터팩(DART 연결 2020-2025 + Naver 실시간) + 웹 리서치 | 주가: 18,240원 (2026-07-01 전일종가)

분류 힌트(스크리닝): 성장 견실주 — 단, Phase 9 Track은 4축 객관지표로 독립 판정.

용어 안내: 이 문서에서 "더마코스메틱(dermocosmetics)"은 피부과학·처방 근거를 강조한 기능성 스킨케어를 뜻한다. "MLE(Multi-Lamellar Emulsion, 다층라멜라 에멀전)"는 피부 각질층 지질 구조를 모사한 네오팜 고유 제형 기술이다. "H&B"는 헬스앤뷰티 스토어(올리브영 등) 채널을 뜻한다. "OP margin"은 영업이익률, "ROIC"는 투하자본이익률, "OE(Owner Earnings)"는 버핏식 오너 어닝(순이익 + 감가상각 − 자본지출)이다.

## 2. 2분 테스트 + 사업모델 (Phase 2)

### 2분 테스트 (Lynch)

네오팜은 **아토피·민감성 피부용 스킨케어(아토팜)와 피부장벽 더마 브랜드(리얼베리어·제로이드·더마비)**를, 국내외 소비자에게, 자체 제형기술(MLE) 기반으로 기획·생산해 H&B·약국·온라인·수출 채널로 팔아서 돈을 번다. 훌륭할 수 있는 이유: **자본을 거의 안 쓰고도(연 capex 매출의 ~1%) 20%대 영업이익률과 13~15% ROIC을 꾸준히 내며 4% 배당까지 주는 현금창출형 니치 브랜드**이고, 여기에 미국 아마존·일본·동남아 **수출이 붙기 시작한 성장 옵션**이 있다.

10살 아이 설명 가능 → **PASS** (아토피용 크림을 만드는 회사, 아기·민감피부 엄마들이 반복해서 사고, 이제 외국에도 팔기 시작함).

### 6-A. 버핏 해자 (프랜차이즈 3조건)

해자 유형별 등급: 브랜드 **MODERATE**(아토팜 니치 헤리티지, 규모는 작음) / 네트워크 **NONE** / 전환비용 **LOW**(반복구매 습관) / 원가우위 **LOW~MODERATE**(자체 MLE 제형·내재화) / 수직통합 **MODERATE**(기획+생산 내재화, 유통 위탁).

### PBR 공식 역산 (`knowledge/할인율_기대수익률.md`)

PBR = ((1+ROE)/(1+r))^N, r = 10%.

- ROE 14.2% 대입: 1.50 = (1.142/1.10)^N = (1.0382)^N → **N ≈ 10.8년** (시장이 ~11년의 초과 ROE 지속을 가격에 반영).
- 경제적 ROE로 ROIC 13.2% 대입: 1.50 = (1.132/1.10)^N = (1.0291)^N → **N ≈ 14.1년**.

해석: 시장은 네오팜에 **11~14년의 초과수익 지속**을 부여 중. 니치 브랜드 + 수출 옵션 감안 시 과도한 낙관은 아니며, 오히려 수출 성장이 실현되면 이 N 가정을 상회할 여지(상방 옵션).

## 10. 간이 3시나리오 Valuation (Phase 10) — 버핏 배정 → 10-A만

현재가 18,240원 / 시총 2,952억 / 주식수 16.18M. 공통 가정: r = 10% 고정, 10년, 세율 22%. 기준 매출 2025 = 1,322억. (순이익률로 직접 모델링 — 네오팜은 순현금 이자수익·낮은 실효세율로 순이익률 ≈ 영업이익률이므로 EBIT×(1−0.22) 대신 순이익률 사용, 데이터팩 근거.)

| 배당성향(누적배당용) | 40% | 40% | 45% |

#### 10-A-2. Risk / Opportunity 매핑 (Phase 8 연계)

| 항목 | Bull 전제 | Base 전제 | Bear 전제 |
| --- | --- | --- | --- |
| Risk #1 지배구조 | 해소(주주환원 강화, 터널링 無) | 완만(현상유지) | 실현(현금 전용·오버행) |

| Opp #3 채널 확장 | 실현(CAGR 견인) | 부분 | 미실현 |

#### 10-A-3. 계산

할인계수 1.10^10 = 2.5937. 터미널 가격 = 10년 EPS × 터미널 PER, 여기에 10년 누적배당(명목, 배당성향×이익성장 반영)을 더한 뒤 할인(누적배당 명목 합산이라 배당가치 다소 과소평가 = 보수적).

- Bull: 매출 1,322×1.12^10 = 4,106억 → 순이익 903억 → EPS 5,582원 → 터미널가 5,582×15 = 83,730원 + 누적배당 ~13,500 = 97,230 → PV = 37,487원
- Base: 매출 1,322×1.08^10 = 2,854억 → 순이익 571억 → EPS 3,527원 → 터미널가 3,527×11 = 38,797원 + 누적배당 ~10,800 = 49,597 → PV = 19,122원
- Bear: 매출 1,322×1.03^10 = 1,777억 → 순이익 302억 → EPS 1,866원 → 터미널가 1,866×8 = 14,928원 + 누적배당 ~9,100 = 24,028 → PV = 9,264원

#### 10-A-4. 결과

| 시나리오 | PV | 현재가 대비 | 실현 CAGR |
| --- | --- | --- | --- |
| Bull | 37,487원 | +105% (2.06x) | ~18.2% |
| Base | 19,122원 | +4.8% (1.05x) | ~10.5% |
| Bear | 9,264원 | −49% (0.51x) | ~2.8% |

**확률가중 PV**: P_Bull 25% × 37,487 + P_Base 50% × 19,122 + P_Bear 25% × 9,264 = **21,250원**
근거 1줄: 수출 인플렉션은 실재하나 초기·검증 부족 + 지배구조/마진 리스크 상존 → Base 중심(50%), 상하방 대칭(25/25).
**현재가 대비**: 21,250 / 18,240 = **1.17x (+16.5%)**

### 10-C. Trigger 신호

- **Bear PV 9,264 < 현재가 18,240**: 극단 저가 신호 아님. 하방 여지가 유의미(−49%) → 마진 안전판 제한적.
- **현재가 18,240 < Bull PV 37,487**: 과신 경고 없음. 상방 여지 존재.
- **Base PV 19,122 ≈ 현재가**: **합리적 구간**. 현재가는 Base 시나리오(연 10.5% 실현)를 대체로 반영. 수출 인플렉션이 상방 옵션.
- 종합: 버핏 DCF 기준 **적정~소폭 저평가(확률가중 +16.5%)**. 강한 저가 트리거도, 과열 트리거도 아님.

### 결정: **Parking Lot**

근거 한 문단: 네오팜은 저자본집약·13~15% ROIC·4% 배당의 **버핏형 현금 프랜차이즈**로 질적 프로필은 준수하고, 수출 인플렉션이라는 상방 옵션도 갖췄다. 그러나 (1) **유니버스 게이트가 MARGINAL**(정례 컨콜·Q&A 전사본 부재로 경영진 발언 대조·지속 검증이 제약), (2) **밸류에이션 매력이 완만**(확률가중 PV/현재가 1.17x, Base 시나리오는 사실상 현재가 반영 = 뚜렷한 안전마진 부재), (3) **잇츠한불 39% 지배구조 + CEO 겸직이라는 미해소 오버행**(순현금 268억의 주주 귀속 여부가 불확실)이 겹쳐, 1~2주 Deep을 즉시 투입하기보다 **분기 재방문(Parking)**이 합리적이다. 재진입 트리거: (a) 수출 비중 25~30% 돌파로 성장 인플렉션 확증, (b) 주가가 52주 저점(~14,000원) 부근으로 조정되어 안전마진 확보, (c) 잇츠한불 지분·현금 전용 관련 지배구조 명확화.

### 확신도: **중간**

방향(버핏형·현금 프랜차이즈)은 서 있으나, C·D축의 피셔 신호 혼입과 마진 추세·지배구조 불확실성이 남아 Deep 중 재확인이 필요한 상태.

### 과신 점검 (Overconfidence Check)

- "왜 싸(적정)한가?" — PER 10x·FCF yield 9%·순현금은 저평가처럼 보이나, 시장은 마진 압축·잇츠한불 지배구조 할인·소형주 유동성 할인을 반영 중일 가능성. Bear PV(9,264)가 현재가의 절반 → "핵심 리스크(지배구조·마진)를 놓치고 있다"는 자문이 유효.
- "왜 이 트랙인가?" — 저재투자·현금환원·안정 ROIC가 버핏형 신호. 다만 수출 성장이 본격화하면 피셔형으로 재분류 여지 → 미정 아님(3:1)이나 재배정 플래그 유지.
- 밸류 트랩 경계: PBR 1.5x·수익성 정상이나, 지배구조發 가치 파괴가 현실화하면 "싼데 더 싸지는" 밸류 트랩 위험. Parking으로 관망 타당.
