## 2. 2분 테스트 + 사업모델 (Phase 2)

### 2분 요약 (Lynch)

Natera는 cell-free DNA 분석 기술로 (1) **산전 검사**(Panorama NIPT, Horizon carrier screening)를 산부인과·여성에게, (2) **종양 잔존암 모니터링**(Signatera MRD)을 종양내과·암환자에게, (3) **장기이식 거부반응 모니터링**(Prospera)을 이식센터·이식환자에게 판다. 산전 검사가 캐시카우로 흑자를 내며 그 잉여를 Signatera 임상 evidence 생성과 R&D에 재투입한다. **가장 훌륭한 점은**: 환자별 종양 시퀀싱 기반의 tumor-informed MRD assay에서 매분기 누적되는 임상 데이터가 경쟁사가 따라잡기 어려운 evidence moat를 만들고, 이 evidence가 다시 Medicare LCD 확장의 우선권으로 작용해 매출·GM·FCF가 동시에 inflection 중이라는 점.

### PBR 공식 역산

`PBR = ((1+ROE) / (1+r))^N`

ROE 음수이므로 원본 공식 직접 적용 불가. **터미널 ROE** 가정으로 시장이 가정하는 (ROE, N) 조합 추론:

- 시장 PBR = 16.5x, r = 10% 가정
- ROE_terminal = 25%, N = 10년 → 적정 PBR = 2.39x → 16.5 / 2.39 = **6.9배 over**
- ROE_terminal = 30%, N = 10년 → 적정 PBR = 5.32x → 16.5 / 5.32 = **3.1배 over**
- ROE_terminal = 30%, N = 20년 → 적정 PBR = 28.2x → 16.5 / 28.2 = **0.59배** (이론적으로 저평가)
- ROE_terminal = 25%, N = 20년 → 적정 PBR = 5.70x → 16.5 / 5.70 = **2.9배 over**

**시장의 함의 가격대로 사기 위해선 ROE 25-30%를 N=20년 이상 유지**해야 함 — 매우 강한 지속성 가정. Fisher Deep Stream C에서 N+1차항·피어 터미널 ROE로 정밀 검증 필요.

> 주의: Fisher 트랙 배정 시 매수 금지 판정에 이 단계 단독 사용 금지(N+1차항 논리). 본격 판정은 Phase 10-B 및 Fisher Deep.

## 10. 간이 3시나리오 Valuation (Phase 10)

피셔형 배정 → **Phase 10-B**(ROE×PBR 복리 CAGR) 수행.

### 10-B. Fisher 분기 — ROE×PBR 기대 CAGR

**전제**:

- 현재 PBR = 16.5x · 자기자본 = $1.71B · 시총 = $28.29B
- N = 10년, r 비교 기준 = 10%
- 이익이 음수인 단계라 형식 ROE 대신 **터미널(인플렉션 후) 지속 ROE**로 가정
- per-share 기준: 본 ROE에서 연 dilution을 차감해 ROE_per-share 도출
- 공식: `r = (1 + ROE_per-share) × (terminal_PBR / current_PBR)^(1/N) − 1`

#### 10-B-1. 시나리오 가정 매트릭스

| 변수 | Bull | Base | Bear |
| --- | :-: | :-: | :-: |
| 터미널 지속 ROE | 30% | 18% | 8% |
| 연 dilution | 3% | 4% | 5% |
| ROE_per-share (= ROE − dilution) | 27% | 14% | 3% |
| 예상 지속 N | 10 | 10 | 10 |
| 터미널 PBR | 5x | 3x | 1.5x |

**터미널 PBR 가이드**: Bull은 evidence moat 강화 + LCD 우위 유지 → 5x · Base는 경쟁 균형 + 마진 정착 → 3x · Bear는 commoditization → 1.5x.

#### 10-B-2. Risk / Opportunity 매핑

| 항목 | Bull 전제 | Base 전제 | Bear 전제 |
| --- | --- | --- | --- |
| Risk #1 LCD 후퇴 | 해소 (적응증 추가 가속) | 완만 (현 6 적응증 유지) | 실현 (CRC ASP 인하) |
| Risk #2 경쟁 H2H 우위 | 해소 (evidence 우위 유지) | 완만 (점유 잠식 일부) | 실현 (Reveal head-to-head 우위) |
| Risk #3 dilution 가속 | 해소 (3% 감속) | 완만 (4% 유지) | 실현 (5%+ 지속) |
| Opp #1 LCD 추가 등재 | 실현 (lung adjuvant 추가) | 부분 (1-2 type 추가) | 미실현 |
| Opp #2 적응증 확장 | 실현 (screening 진입) | 부분 | 미실현 |
| Opp #3 흑자 정착 | 실현 (5년 내 EBIT +20%) | 부분 (5년 내 +10%) | 미실현 (영구 -5% 마진) |

#### 10-B-3. 계산 + 결과

| 시나리오 | 기대 CAGR | 판정 (10-C 참조) |
| --- | :-: | --- |
| Bull | **+12.7%** | 매수 가능 후보 (10% 초과) |
| Base | **−3.9%** | 매수 부적합 구간 |
| Bear | **−19.0%** | 손실 구간 |

**확률가중 CAGR**: P(Bull 30%) × 12.7 + P(Base 50%) × (−3.9) + P(Bear 20%) × (−19.0) = **−1.9%**

- 확률 추정 근거: Druckenmiller 14분기 보유 + 분기 KPI 검증이 누적되어 Bull/Base 가능성 높이지만, **현재 PBR 16.5x가 Bull 가정의 대부분을 이미 가격에 반영**하고 있어 Base를 보수적으로 50%로 둠.

### 10-C. Trigger 신호

- **Bull CAGR 12.7% ≥ 10%** → 매수 가능 후보 ✓ (Deep 필수)
- **Bull CAGR ≥ 4%** → 매수 금지 trigger 미발동 ✓
- **Base CAGR < 4%** → 가격 stretched 신호. Bull 가정 의존도 매우 높음
- **확률가중 CAGR 음수** → Margin of safety 매우 얇음

종합: 매수 금지는 아니나 **현재가에서의 신규 진입은 Deep에서 추가 확인 필요**. 인플렉션 가속 vs LCD 후퇴 트리거를 모니터링하면서 분할 진입 또는 가격 조정 대기가 합리적.

### 10-D. 참고 — 조감용 시나리오 비교

| --- | :-: | :-: | :-: |

### 종합 확신도: **중간**

- **Track 배정**(Fisher): **높음** — 4축 일치, 의문 없음
- **가격 축**: **낮음** — 현재 PBR 16.5x는 Bull 가정 대부분을 가격에 반영, Base CAGR 음수
- **사업 축**: **중간-높음** — inflection 시그널 명확하나 LCD 의존성과 경쟁 H2H 외생 변수 큼

→ **Deep Dive 진입은 YES, 단 Fisher Deep Stream C(EPS×PER 4시나리오 + 피어 터미널 PER + Reverse 역산)에서 시장 함의 멀티플의 정합성을 정밀 검증할 것**. 현재 가격의 Bull 의존도가 높으므로, 매수 시점 결정은 Deep 완료 후 분할 진입 또는 (a) GM 70% 진입 (b) 영업마진 +500bps/yr 페이스 유지 (c) 추가 LCD 등재의 catalyst 시점에 재검토.

### 과신 점검

- "왜 비싼가?": **Druckenmiller 14분기 보유 + 분기 KPI 검증 누적 + LCD 확장이 외생 일정표** → 시장이 inflection의 가속·지속을 강하게 가격에 반영. PBR 16.5x는 ROE 30% × N=10 가정과도 정합성이 안 맞을 만큼 stretched.
- "내가 성장 동력 과소평가?": MRD 적응증의 비선형 TAM 점프 + Signatera screening 진입 가능성 = 현재 시장 가정보다 큰 상방. 그러나 그 시나리오가 *이미 Bull*이고, Bull CAGR이 12.7%에 그치는 것이 시장의 가격 의미.
- "왜 이 트랙인가?": 4축 모두 Fisher. 재투자 강도 + ROIC 수렴 + 가이던스 성격이 전형적 inflection 단계 성장주 패턴.

### 종합 결론

**Fisher Deep 진입 권장**. Deep에서 (1) 분기별 unit volume + ASP의 inflection 지속성 검증 (2) Guardant H2H 임상 비교 (3) dilution 감속 패턴 (4) 매출×마진 시나리오의 reverse DCF 검증을 핵심 4축으로 진행. 매수 결정은 Deep 완료 + 외생 catalyst (LCD / 임상 / 분기 IR) 재확인 후.
