# 퓨릿(445180) Shallow Dive — 2026-07-01

기준일: 2026-07-01 | 데이터: 데이터팩(DART 개별재무 2023-2025 + Naver 실시간) + 웹 리서치(IR·언론·증권사 리포트) | 주가: 8,320원 (2026-07-01, 전일종가)

한 줄 요약: 반도체 포토(노광) 공정용 신너(thinner)의 **원재료(PGMEA·PGME·EEP·EL)를 국산화**해 파는 한국알콜그룹 수직계열 소재사. 저평가(PER 8.6·PBR 1.3)이지만 **상장 2.7년(게이트 미달) + 특수관계자 매출 66%(지배구조 불투명) + 반도체 순환성**이 Deep 진입을 막는다 → Parking Lot.

## 2. 2분 테스트 + 사업모델 (Phase 2)

### 2분 테스트 (Lynch)

> 퓨릿은 **반도체·디스플레이 포토(노광) 공정에 쓰이는 신너(thinner)의 핵심 원재료 화학소재(PGMEA·PGME·EEP·에틸락테이트 EL)** 를, 신너 완제품을 만드는 화학사(이엔에프테크놀로지·동진쎄미켐·듀폰 등)와 반도체 소자업체(삼성전자·SK하이닉스·인텔)에게, **국내에서 합성·고순도 정제해** 팔아 돈을 번다. 과거 전량 수입에 의존하던 소재를 **국산화(EL 국내 유일, 점유율 약 40%→50% 목표)** 해 수입대체·물류비 절감·납기 우위로 성장할 수 있다는 것이 투자 포인트다.

설명 가능 → 통과. 단 "원재료의 원재료"에 가까운 **밸류체인 상류(intermediate)** 라 최종 수요와 두 단계 떨어져 있고, 매출의 다수가 그룹 관계사 경유라는 점이 이해의 복잡도를 높인다.

### PBR 공식 역산

```text
PBR = ((1+ROE)/(1+r))^N  →  r = (1+ROE)/PBR^(1/N) − 1
```

경제적 ROE 대리치로 ROIC(≈15%) 또는 보고 ROE(15%) 사용, PBR 1.32:

- r = 10% 가정 시 시장 함의 N: `1.32 = (1.15/1.10)^N` → `1.32 = 1.0455^N` → N ≈ **6.2년** (시장은 ROE 15% 초과수익을 약 6년만 반영 — 짧은 편, 순환/지배구조 디스카운트 반영으로 해석)
- 역으로 ROE 15%·N=10 고정 시 함의 r: `r = 1.15/1.32^0.1 − 1 ≈ 11.9%` → 현재가에 사면 장기 ~12% 기대(모트 소실·터미널 PBR 1.0 가정)

→ **저평가 시그널**: 시장이 초과수익 지속기간을 보수적으로(6년) 가정. 이유(순환성·특수관계자 66%·짧은 상장 이력)가 설명되므로 value trap 여부는 지배구조 검증에 달림.

**확신도: 중간** (트랙 방향은 피셔로 명확, 밸류는 매력적이나 게이트·지배구조가 Deep 진입을 막음)

| 판단 요소 | 상태 |
| --- | --- |
| 유니버스 게이트 | MARGINAL(상장 2.7년·컨콜 Q&A 부재로 실질 미통과) → Deep 자격 미달 |
| 2분 테스트 | 통과(설명 가능) |
| 정량 5개 PASS ≥ 3 | 3.5/5(경계) |
| Track Gate 확신도 | 피셔형·중간 |
| Phase 10 가격 축 | 장애 없음(Base 12%·Bear 5% ≥ 4%) — 매력 |
| 결정적 장애 | **Phase 1 게이트 + 특수관계자 66% 지배구조 불투명** |

### 왜 Deep 진입이 아닌가

밸류에이션(PER 8.6·PBR 1.3·Base CAGR ~12%)과 피셔형 성장 서사는 매력적이지만, (1) **상장 5년 미만(2.7년)** 으로 경영진 트랙레코드·공시 성숙도가 부족하고, (2) **정기 컨퍼런스콜/Q&A 전사본 부재**로 경영진 판단을 검증하는 피셔 프레임의 본체 자료가 얇으며, (3) **매출의 66%가 그룹 관계사 경유**라 보고 ROE 15%가 소수주주 가치로 온전히 귀속되는지 확인 불가하다. 이 세 가지는 Shallow 자료로 해소되지 않는다.

### 재방문 트리거 (Parking Lot 조건)

- 상장 5년 경과(2028-10 이후) — 공시·경영진 이력 성숙
- 3공장 가동 실적 + **비관계사(독립) 고객 매출 비중 상승** 확인 → 지배구조 디스카운트 완화 증거
- 반도체 다운사이클 저점에서의 실적 방어력 재확인(2023형 스트레스 테스트)
- 2차전지/NMP 신사업 매출 실현 여부

### 과신 점검 (Overconfidence Check)

- Bear IV가 현재가의 2배 초과 아님, 현재가가 Bull IV의 2배 초과 아님 → 극단 미스프라이싱 신호 없음
- PBR 1.32(1 이상)이므로 "수익성 기업 PBR<1 미스터리"는 해당 없음
- Track 4축이 2:2 혼재가 아닌 4:0(피셔) → 트랙 배정 자체는 직감 아님
- **핵심 미스**: 특수관계자 거래의 소수주주 영향은 Shallow로 판정 불가 — "성장의 질"에 대한 확신이 없으므로 Deep 자격 부여 보류가 타당

## 회고 (뼈대에 부족했던 것)

- **CAPEX·R&D·현금 세부 결측**: 데이터팩이 개별재무(OFS) 요약이라 FCF·ROIC·재투자율을 정밀 산출 못 함. 피셔형 판정의 B축(재투자율)이 추정에 의존 → Deep 진입 전 DART 사업보고서 현금흐름표·주석 필수.

- **특수관계자 정량**: 66% 비중은 확인됐으나 전이가격/매출총이익률 영향은 미확인 — Shallow 게이트가 "지배구조 축"을 별도로 다루면 이런 그룹 캡티브 종목의 조기 스크리닝에 유용할 듯.
