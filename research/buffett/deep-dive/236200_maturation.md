# 슈프리마(236200) 숙성기 — 미개시

상태: **미개시** — Stream 6 결정이 "탈락(질) · 재진입 조건부"이므로 숙성기(Stream 7)는 시작하지 않는다. 숙성기는 편입 초안이 나온 뒤 2~4주 시간 필터를 거는 장치다 (`playbook/deep-dive/07_maturation.md`). 013030 전례(탈락 초안도 숙성 운영)와 달리 미개시하는 이유: 본 건은 재진입 조건 5건이 날짜로 잡힌 '재판정 예약' 상태라 `236200_monitoring.md`의 조건 워치가 시간 필터를 대체하기 때문이다.

## 개시 조건

`236200_monitoring.md`의 재진입 조건 1~3 충족 + 조건 4 역방향 부재 → #15 재판정 → Stream 6 재실행에서 **편입 초안**이 나오면 그 시점부터 개시.

## 개시 시 캘린더 뼈대 (미리 준비)

| 시점 | 작업 |
| --- | --- |
| 0주차 | 숙성기 시작 선언, 종료 일자 확정 (2~4주 뒤, 분기 실적 이벤트 1회 포함되도록) |
| 1주차 | Deep 리포트(`236200_슈프리마.md`) 재독 1회차 — 흔들리는 지점 기록 |
| 2주차 | 경쟁사·섹터 보조 독서 (Verkada·HID·아이디스 최근 분기, ISC West 동향) |
| 3주차 | Deep 리포트 재독 2회차 |
| 분기 실적 시점 | 잠정실적 공시 실시간 관찰 — 부문별 매출·OPM·주주환원 이행 (컨콜 부재 종목이므로 공시+IR자료로 대체) |
| 종료 | 종료 체크리스트 5항 → 편입 재확정 / 워치 강등 / 탈락 |

## 체크리스트 → 결정 매핑 (개시 후 사용)

| 관찰 | 결정 영향 |
| --- | --- |
| 분기 이벤트·재독에서 초안을 흔드는 신호 없음 + 낙관 가정 유효 | 편입 초안 **재확정** → 분할매수 실행 계획 개시 |
| 형용사 추가·가정 일부 약화 등 확신 저하 신호 (결정 뒤집을 정도는 아님) | **워치 강등** → `236200_monitoring.md` 관찰 모드로 이관, 재판정 허들 상향 |
| #15 재판정 근거를 뒤집는 신호 또는 재진입 조건 4 역방향 발동 | **탈락** → 편입 초안 철회, 재진입 워치 종료 검토 |
